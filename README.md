# Daiki Portfolio

Professional portfolio scaffold for Adrian Melgar, branded as Daiki.

## Stack

- Vite+
- Vue
- TypeScript
- Tailwind CSS
- shadcn-style Vue components

## Commands

- `vp install`
- `vp dev`
- `vp check`
- `vp build`

## Content

Portfolio content lives in `src/data/portfolio.ts`.

Projects are local data for v1 and can later load from a database or API.
